ROS 2 Basic for Mobile Robot (สอนสด)

by TESR Academy

คอร์สนี้เหมาะกับคุณไหม

สอนสด 2 วัน เริ่ม ROS 2 ตั้งแต่ติดตั้ง จนสั่งหุ่นยนต์ iron-x สร้างแผนที่และวิ่งอัตโนมัติได้เอง

  • สอนสด 2 วัน
  • ฝึกกับหุ่นยนต์ iron-x จริง
  • ฟรี Online Course 37 บทเรียน

เรียนจบแล้วทำได้

  • ติดตั้ง ROS 2 บน Windows ผ่าน WSL2 และใช้คำสั่ง Linux กับคำสั่ง ROS 2 พื้นฐานได้
  • ตั้งค่าเครือข่าย ROS 2 และควบคุมหุ่นยนต์ iron-x ด้วย Joystick หรือคีย์บอร์ด
  • สร้างแผนที่ด้วย SLAM และสั่งหุ่นยนต์เดินทางอัตโนมัติด้วย Navigation
  • อ่านข้อมูล LiDAR และ IMU เขียน Python สั่งงาน Navigation และทำ Dashboard ด้วย Node-RED

เหมาะกับ

  • นักศึกษา วิศวกร และผู้สอน ที่อยากเริ่ม ROS 2 กับหุ่นยนต์จริง
  • ผู้ที่มีหรือกำลังจะใช้หุ่นยนต์ iron-x หรือ AMR ในงาน
  • ไม่จำเป็นต้องมีพื้นฐาน ROS มาก่อน

ต้องเตรียม

  • Notebook Windows 10 หรือ 11 จำนวน 1 เครื่อง
  • ได้สิทธิ์เรียน Online Course ROS 2 Basic ฟรี (37 บทเรียน ประมาณ 6.2 ชั่วโมง ทั้งเวอร์ชัน Humble และ Jazzy)
